# 🌿 Dompetku - Praktikum PAB Pertemuan 7

Aplikasi **Dompetku** merupakan aplikasi pencatatan pengeluaran sederhana berbasis Flutter yang dikembangkan untuk memenuhi tugas Praktikum Pemrograman Aplikasi Bergerak (PAB) Pertemuan 7.

Aplikasi ini menerapkan penggunaan ListView, GridView, TabBar, serta Image untuk menampilkan dan mengelola data transaksi pengeluaran.

## ✨ Fitur Aplikasi

1. **Transaksi**
   - Menampilkan daftar transaksi pengeluaran.
   - Menghitung total pengeluaran secara otomatis.
   - Menggunakan ListView.builder.

2. **Kategori**
   - Menampilkan kategori pengeluaran dalam bentuk grid 2 kolom.
   - Menggunakan GridView.builder.
   - Menampilkan jumlah transaksi dan subtotal setiap kategori.

3. **Profil**
   - Menampilkan gambar profil dari assets.
   - Menampilkan gambar sampul dari internet.
   - Menampilkan informasi program studi dan mata kuliah.

4. **Statistik**
   - Menampilkan transaksi dengan nominal pengeluaran terbesar.
   - Memperbarui hasil berdasarkan transaksi terbaru.

5. **Tambah Transaksi**
   - Menambahkan transaksi baru.
   - Memilih kategori pengeluaran melalui dropdown.
   - Melakukan validasi input judul dan nominal.
   - Memperbarui total pengeluaran secara otomatis.

## 🚀 Cara Menjalankan Aplikasi

1. Clone repository:

```bash
git clone https://github.com/USERNAME/202432027_AmandaDamayanti_Prak7_PAB.git
```

2. Masuk ke folder project:

```bash
cd 202432027_AmandaDamayanti_Prak7_PAB
```

3. Install dependencies:

```bash
flutter pub get
```

4. Jalankan aplikasi melalui Chrome:

```bash
flutter run -d chrome
```
